## 0.5 已定的决策（别反复推翻，改之前先问用户）

| 决策 | 结论 | 原因 |
|---|---|---|
| 广告平台 | **AdMob**（不接国内平台），分发专注 Google Play | 与 Play 分发一致、合规方案现成；国内渠道暂缓 |
| 广告形态/位置 | **只在媒体库页底部一条自适应横幅**；无插屏、无开屏；播放页永不放 | 播放控制是命脉，任何打断都是自毁 |
| 广告与免广告 | 是否展示只由 `AdPolicy` 决定，将来接 Billing / 激励视频 | 一处开关，业务代码不散落判断 |
| 意见反馈 | 走**用户自己的**邮件/系统分享渠道，App 不做内置发送、不搭后端 | 零凭据零风险；隐私政策好写 |
| 本机播放 | 只做**音频**（Media3 ExoPlayer）；视频交系统播放器；图片用内置预览页 | 视频解码体积/许可成本高，交给 VLC 更实际 |
| 手机本地音乐 | 只索引 **MediaStore 已入库**的音频，不申请全盘存储权限 | 权限最小化，代价是散落文件不在索引里 |
| 单元测试 | **不新增**，验证靠"编译通过 + 真机手动验证" | 用户明确要求（仓库既有单测可跑回归） |
| 收费方向 | 服务器助手（清理/整理/推荐）+ 去广告；现在全部免费（`EverythingFreeGate`） | 先把产品做扎实 |

## A. 发布前必须完成（不完成就发不出去）

### A1. 只有用户能做（AdMob / Play 后台操作）

- [ ] **补齐 AdMob 付款资料** —— 后台红条提示 *Payment setup incomplete … apps in review will remain
      unreviewed until you add your payment information*，也就是 `Approval status: Getting ready` 卡住的原因。
      入口：AdMob → Payments → **Manage settings**（跳到 AdSense 中国），需依次完成：
      付款姓名与地址（须与证件/银行一致）→ 纳税人信息（W-8BEN）→ 付款方式（电汇银行账户英文信息 +
      SWIFT，账户名须与付款姓名一致）→ 地址验证 PIN 明信片（收益累计约 $10 时寄出）→
      Verification 页如有要求需上传身份/地址证明。起付额 **$100**，每月结算。
- [ ] **配置同意消息**：AdMob → Privacy & messaging → GDPR 建一条消息。
      未配置时 UMP 会报 `Publisher misconfiguration … no form(s) configured for the input app ID`；
      代码已降级处理（不影响功能），但**面向欧洲发布前必须配置**。
- [ ] **确认广告单元 `1536397739` 是「横幅」格式**：填成插屏/原生/激励会导致 `AdView` 一直加载失败。
      另外：**不需要配置 Mediation（中介）**，那是接入第三方广告源用的，我们只投 AdMob 自己的广告。
- [ ] **Google Play Console 建应用**：商店 listing（名称/简介/描述/截图/feature graphic 1024×500）、
      内容分级问卷、**Data safety**（申报广告 ID 用于「广告或营销」）、
      勾选「**应用含广告**」、上传 AAB（内部测试轨道优先）。
- [ ] **准备隐私政策公开网址**（Play 必填）：可把 `docs/10-隐私政策.md` 发布到 GitHub Pages
      等静态托管。目前 App 内文案写的是"公开网页地址暂未提供"，上架前需替换。
- [ ] **上架后**把 Google Play 补进 AdMob 的 App store details（现在填的是 OPPO/三星/VIVO/小米 GetApps）。

### A2. 代码/构建侧（助手可以做）

- [ ] **真图标 + 自适应图标 + 启动图**：现在是 Android 模板图标，是商店审核与第一印象的硬伤。
      需要 512×512 Play 图标、`mipmap-anydpi-v26` 自适应图标（前景/背景）、可选 splash。
- [ ] **`values-en` 英文文案**：面向 Play 海外用户；中文为主，英文只翻 UI 文案。
- [ ] **商店素材**：4–8 张手机截图（媒体库/播放页/服务器曲库/搜索/设置）、feature graphic、描述文案。
- [ ] **release 包回归**（**唯一需要用户配合跑**，因为要用签名密码）：
      ```powershell
      $env:GRADLE_USER_HOME='<工程根>\.gradle-home'
      .\scripts\build-direct-release.ps1
      adb uninstall com.havencast.remote      # debug 与 release 签名不同，必须先卸载（会清数据）
      adb install -r app\build\outputs\apk\release\app-release.apk
      adb logcat -s HavenCast | Select-String '\[AD\]'   # 期望：SDK 初始化完成 -> READY（真实广告）
      ```
      这一步同时验证 R8 压缩没有破坏广告 SDK 与 UMP。
- [ ] **收紧明文流量**（可选但推荐）：清单里 `usesCleartextTraffic="true"` 是全放开，
      可改为 `network_security_config` 只允许局域网私网地址走明文。
